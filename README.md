# hotel-overbooking-optimization
Predict hotel booking cancellations and optimize overbooking decisions using machine learning and probabilistic simulation.

## Skills Demonstrated

**Programming & Data Analysis**
- Python, Pandas, NumPy
- Data Cleaning and Exploratory Data Analysis
- Feature Engineering and Data Visualization

**Machine Learning**
- Binary Classification
- Logistic Regression and Random Forest
- Classification Metrics and Model Evaluation

**Statistical Modeling & Decision Science**
- Cancellation Probability Estimation
- Monte Carlo Simulation
- Overbooking Risk Analysis
- Capacity-Constrained Optimization

**Business Application**
- Hotel Revenue Management
- Room Inventory Planning
- Risk-Based Booking Recommendations
